♞ Analyse Echecs

Les parties, analyses et réglages sont gardés sur cet appareil.

À propos

Analyse Echecs est une application gratuite pour analyser ses parties chess.com, Lichess ou PGN : classement des coups, précision, Elo estimé, graphique d'évaluation, exercices tirés de vos erreurs, progression, jeu contre Stockfish et répertoire d'ouvertures. Elle n'est affiliée ni à chess.com ni à Lichess.

Crédits

  • Moteur : Stockfish 19, par l'équipe Stockfish (stockfishchess.org). Licence GPL v3. Code source : github.com/official-stockfish/Stockfish. Version web : stockfish.js de Nathan Rugg (GPL v3), chargée depuis unpkg.com.
  • Analyse cloud et tables de finales : Lichess, via son API publique.
  • Base d'ouvertures : lichess-org/chess-openings, domaine public (CC0).
  • Pièces : jeu « cburnett » de Colin M. L. Burnett, licence CC BY-SA 3.0.
  • Parties : API publiques de chess.com et de Lichess (parties terminées uniquement).
  • Formules : chances de gain et précision d'après celles de Lichess.

Vos données

Votre pseudo, vos parties et vos analyses restent sur cet appareil. L'application ne les envoie nulle part, à part les positions interrogées auprès de Lichess pour l'analyse cloud.
